## Workflow folders

```text
minimax-h3/
├── t2v/
├── fl2v/
└── ref2v/
anima/
qwen-image-2.1/
```

Workflow JSON files go directly in the matching folder, with descriptive names such as `h3-ref2v-lora-name.json`, `anima-lora-name.json`, or `qwen-image-2.1-lora-name.json`.

MiniMax H3 workflows are grouped by generation mode: T2V, FL2V, and Ref2V. Anima and Qwen Image 2.1 workflows go directly in their model folders. New model folders will be added as needed.

To add a workflow, open the matching folder on GitHub and choose **Add file → Upload files**. Each folder contains a small `.gitkeep` file so it is available before any workflows are uploaded; you can leave it in place.
