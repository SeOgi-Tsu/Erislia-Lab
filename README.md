# ComfyUI Workflows

My personal collection of ComfyUI workflows and LoRA experiments, organized by model and generation mode.

Currently focused on MiniMax H3: **T2V**, **FL2V**, and **Ref2V**. More models will be added over time.

[X / Twitter](https://x.com/dream_weebs) · [YouTube](https://www.youtube.com/@%E6%A2%A6%E5%BD%B1Erislia)

## Organization

```text
minimax-h3/
├── t2v/
├── fl2v/
└── ref2v/
```

Workflow JSON files go directly in the matching folder, with descriptive names such as `h3-ref2v-lora-name.json`. New model folders will follow the same structure where applicable.
